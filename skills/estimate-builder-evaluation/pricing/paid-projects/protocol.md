# Locked comparison for reported project expenditures

Use 2023 AHS national public-use v1.1. Before examining cost values or split results, fix the following rules. Include owner-occupied interviews, completed jobs with most work done outside the household (JOBDIY 2), positive reported cost, and unallocated completion, cost, project type and DIY fields (J flags 0). Exclude broad residual types 31 and 37. Group repeated records by household for a deterministic holdout: SHA-256 of stripped CONTROL, first 8 hex digits modulo 5, remainder 0 is test. No cost data from test households enter the reference table.

Compare three point estimates: the common training median across all eligible jobs, the median for the project type (minimum 20 train records), and the project type plus Census division median (minimum 40 train records). Fall back to the project median if a regional cell is sparse. Abstain if the national project minimum is not met. Evaluate paired estimates over exactly the same test records, giving each sampled job one vote. Report coverage, MAE, median absolute error, signed bias, percent within 25%, and empirical coverage of the training 10th–90th percentiles. Publish grouped counts/errors including regressions. Accuracy is prediction of a historical reported expenditure; individual scope, exact labor share, grade, permits, crew experience and invoices are unavailable. These unweighted sample benchmarks are not population estimates. Currency is nominal dollars at the time of work. Use geography only when its incremental performance warrants it.
