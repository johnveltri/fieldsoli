# First response to 100 homeowner requests

Use only the original request from each numbered case in the 100-request suite. Withhold the contractor’s later answers, prices, baseline responses and expected results. Each request starts a new scenario with the estimate builder invoked. Record the entire first reply before review. Review the customer-visible output as well as any contractor questions. A reference to a future estimate or an offer to provide a breakdown earns no credit.

1. Check for a specific base deliverable with an amount, including TBD when open. Check that separately requested tasks are visible, including when a single bundled charge covers them. A preliminary inspection or fit check may be the only supported service. Preserve a requested structured format and an existing quote’s scope.
2. For each material finding that might add chargeable work, look for a distinct conditional row with the observable trigger, proposed work and amount or TBD. Verify that the customer can approve that work separately and that it is outside the base total. A selection the customer can make now, a scope boundary or a referral by itself is not an extra charge. A requested optional service and a mutually exclusive alternative must be identified as such.
3. Check the actual amounts and base total. The hood and screen-door customer budgets are not agreed prices. Two existing bids in the intake do have amounts. Later contractor prices from the original conversations are unavailable in this run.
4. Review the existing-bid review (76), structured request (90), and active water leak (95) on their own terms. Preserving the bid while showing its current lines is compatible with review before rewriting. A structured items array counts as itemization. For an active hazard, immediate action takes priority over any proposed follow-up work.
5. Record any formatting or substantive gap by case number. Retest failed cases from the original request alone after correcting the skill, keeping the first run available for comparison. Record the denominator, exceptions and which cases were retested.
