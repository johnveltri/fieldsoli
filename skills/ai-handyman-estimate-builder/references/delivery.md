# Estimate delivery

Use the latest edited estimate as the source for every requested format. Preserve line IDs, wording, quantities, price qualifiers, package coverage, TBD checks and total treatment. Recalculate after edits. Moving a condition into a package requires the contractor to confirm coverage and any price effect. Replacing a base repair with an alternative removes the replaced charge from the selected total.

## Editable first pass

Show the draft directly in chat, with contractor review followed by the homeowner estimate. Use stable IDs and ordinary Markdown that the handyman can copy and edit. A file download is optional. Close with a brief offer such as “You can edit any row here, save Markdown, prepare a PDF or draft the homeowner email.” Do not make choosing a format a prerequisite for receiving the estimate.

Example using supplied contractor figures only

Contractor says “Replace the owner's dishwasher for $250 including removal, haul-away, hookup to existing services and leak testing. Valve operation and fit still need checking. A new connector is required, but I haven't priced it. If the shutoff fails, I'll quote replacement separately.”

Scope draft — pricing to follow.

| ID | Line item and scope | Quantity/unit | Amount | Total treatment | Verification needed |
|---|---|---|---|---|---|
| L1 | Replace owner-supplied dishwasher, remove and haul away old unit, connect to existing services and leak-test | 1 appliance | $250 | Base scope — included in priced subtotal | Contractor checks model dimensions and opening before booking. Fit remains pending and may change installation scope. |
| L2 | Supply required compatible connector | 1 connector | TBD | Base scope — price pending | Contractor confirms the model's connection requirements and supplier price before finalizing the estimate. |
| C1 | Replace existing shutoff valve if it fails the operation check | Quantity pending inspection | TBD | Outside base — approval required | Contractor tests the valve before disconnecting. If it fails, confirm who can replace it and quote the repair before approval. |

Priced subtotal $250. Complete base total TBD because L2 is unpriced. C1 is excluded from the priced subtotal and complete base total. Show the failed valve and obtain approval of the repair scope and price before additional work begins.

Ask the consequential fit question alongside this draft. Do not let the example's prices or responsibilities become defaults for other jobs.

## Markdown save

When asked to save, create a downloadable `.md` file using available file tools and link to the actual file. Use a descriptive job filename and revision suffix when retaining an earlier version. Default to the homeowner estimate. Include contractor review in a separately labeled section only when the handyman requests a working copy with notes. State which copy was saved. If file creation is unavailable, provide the complete Markdown in a copyable code block and explain how to save it. Report the available result accurately.

## Homeowner PDF

When requested, create an actual PDF with available document tools. Include supplied contractor/customer information, job title and location, estimate date, revision, scope rows, known quantities, amounts, total treatment, verification needed, totals, owner responsibilities and agreed terms. Omit absent contact fields and terms. Use a draft label while material scope or prices remain unresolved. An unresolved estimate can still be shared as a clearly labeled draft when requested.

Keep contractor review, research comparisons and internal confidence notes out of the PDF. Retain homeowner-relevant TBD checks, exclusions and approval terms. Preserve researched planning labels when applicable. Wrap long row text, repeat table headers across pages, and keep totals legible. Visually inspect rendered pages and check extracted text and arithmetic against the current estimate before delivery. Link the saved PDF. If PDF creation is unavailable, supply the homeowner copy with print-to-PDF instructions and accurately describe the result.

## Homeowner email

Prepare an email with a descriptive subject, short greeting, scope, the estimate's line-item breakdown or the requested PDF attachment, totals and pending verification. An inline email must preserve all rows and their total treatment. When attaching a PDF, identify it and summarize the priced subtotal, incomplete base total and material pending items. Include the agreed next step and additional-work approval terms. An email draft is a usable deliverable when the contractor asks for wording.

For sending, use an available connected email tool with a confirmed recipient and the contractor's authorization for this send. “Draft an email” authorizes preparing text. If asked to send and the recipient is missing, prepare the email and requested attachment, then request the address. If no sending tool is available, provide the subject, body and requested attachment for manual sending. Verify the tool result before reporting sent status. Saving or sending an estimate does not record homeowner acceptance or authorize additional work.

## Revision and handoff check

Check that each independent deliverable and credible condition has a row, each TBD identifies its verification and total treatment, and amounts reconcile without double-counting packages or alternatives. Verify every requested format against the latest edited rows. A supplied fixed package stays intact until the contractor changes it. Remove stale wording after a condition is resolved. Keep unselected options outside the base.

Prepare these files for human review and sharing. Claim Jobber, Housecall Pro or another platform import compatibility only after verifying its current supported format and testing the mapping. An emailed attachment alone supplies no evidence of an editable platform import.
