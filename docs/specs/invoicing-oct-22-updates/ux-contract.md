# UX contract

| ID | Surface and behavior |
| --- | --- |
| UX-01 | Job and Business address fields reuse existing panel: eligible search shows `Searching…`, successful empty response shows `No results`, failure hides panel and preserves manual entry. At most four results; footer `Powered by Geoapify · © OpenStreetMap contributors`. Selection respects focus/keyboard and draft Done/cancel. Do not save each keystroke. |
| UX-02 | FAB and Job Edit preview have equivalent access across statuses. Saved document remains read-only; unsaved type selector follows STATE-02. Return from app switch restores the same preview with visible loading then content or `Could not load this document.` and `Retry`. Cached offline preview retains existing offline warning and fresh-read action restrictions. Loading never traps the user. While authenticated Job View is active, prepare its default live preview and embedded fonts in the background; opening the FAB reuses a successful preparation up to 30 seconds old. Reveal the WebView only after fonts and its first paint are ready; a 15-second render timeout offers Retry. |
| UX-03 | Material row retains primary cost. Beneath it, right-align `{amount} with markup` in existing bodySmall/secondary foreground with standard spacing. No new icon/card. Include zero markup, omit unknown charge, preserve quantity and actions. Large text may grow row; never overlap/truncate money. VoiceOver says cost and price with markup distinctly. |
| UX-04 | Shared renderer displays US phones as `(000) 000-0000`, normalizing leading US country code for display. Preserve other formats/extensions. Verify all renderer consumers and escaping. |
| UX-05 | SMS To field receives validated saved phone only, otherwise no recipient. Do not fabricate a contact or use customer name as phone. iOS may display a contact label for a supplied valid number; diagnose this on-device without promising control of native contact labels. Cancel restores preview. |
| UX-06 | Unknown/disabled/archived/deleted link: `Invoice/Estimate no longer exists.` No title, number, name or old image. Outage retains `This document is temporarily unavailable. Please try again.` and Retry. |
| UX-07 | SMS: `Invoice for {formatted full total} from {business name}\n{url}` or Estimate equivalent. Use the shared body helper consistently for link-share destinations; email subject retains number. Rich card emphasizes business and amount, shows Invoice/Estimate and immutable Job short title, with small `Shared with FieldSoli`. Metadata title `{type} from {business name} — {amount}`; description is immutable short title. No number needed on card; actual document keeps number. Card wraps/ellipsizes long business/title without losing type/amount. No new tracking/assets/provider needed. |
| UX-08 | Zero markup/tax focus shows an empty numeric draft; typing replaces zero. Empty blur restores zero; nonzero focus preserves value. Existing validation/range, Done/cancel and decimal keyboard apply. Focus alone never enables save. |

Reuse existing rows/panels and platform input/composer rather than new libraries. Capture current and changed material row on matching device/state; check secondary contrast, VoiceOver, large type, safe areas, keyboard selection and touch targets. Screenshot verification is pending implementation; this contract is not a visual audit result. Browser page/metadata and native iMessage rendering require separate evidence. Destination preview caching is outside application control.
